# Cybersecurity-Compliance-Analysis
# Network Anomaly Detection & ISO 27001/28000 Risk Reduction Framework

## Executive Summary
Analyzed over 49,000 network traffic logs to identify active DDoS threats on web servers. Designed a data-driven simulation demonstrating how implementing **ISO/IEC 27001** and **ISO 28000** compliance controls reduces network risk exposure by **92%** and mitigates financial downtime losses.

## Key Technical Tools
- **Data Engineering:** Python (Pandas, NumPy)
- **Database Querying:** Microsoft SQL Server Management Studio (SSMS)
- **Risk Simulation:** Python (Monte Carlo / Rule-based Risk Scoring)
- **Data Visualization:** Matplotlib / Seaborn

## Key Findings & SQL Metrics
- **Total Traffic Analyzed:** 49,787 events
- **Threat Detected:** 23,865 DDoS flood attacks targeting **Port 80 (HTTP)**
- **Baseline Risk Exposure:** 47.93% of total network traffic

## Compliance Impact & ROI (ISO 27001 A.12.1.2)
- **Risk Rate Reduction:** Reduced from 47.93% to **3.83%**
- **Potential Downtime Mitigated:** Reduced from 48 hours to **3.8 hours**
- **Cost Savings:** Estimated **$220,800 saved** in supply chain downtime losses
